Stack:

- [Fiber v3](https://docs.gofiber.io) — web framework
- [Redis](https://redis.io) — caching via `go-redis/v9`
- [GraphQL](https://graphql.org) — unified API via `graphql-go/graphql`
- [Swagger](https://swagger.io) — API docs via `swag` + `swaggerui`
- [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) — Cloudflare bypass (custom fork)
- [Docker](https://docker.com) — multi-stage Alpine build
- [Taskfile](https://taskfile.dev) — task runner
- [GitHub Actions](https://github.com/features/actions) — CI/CD
